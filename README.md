# openvmx-site

Landing page for **OpenVMX** — an open-source, OpenVMS-compatible environment for Linux.

- Live: https://openvmx.3dl.dev
- Source project: https://github.com/3dl-dev/vms

Static single-page site (`index.html`), served by GitHub Pages. No build step.
Design: DEC engineering-document treatment (Helvetica × monospace, VMS-manual palette).

## Deploy
Push to `main`; GitHub Pages serves the repo root. `CNAME` binds `openvmx.3dl.dev`.
