Documentation set

OpenVMX manuals

This set describes how to build, install, and run OpenVMX. Each manual covers one task and states what the current release does. Where a facility is not implemented yet, the text says so rather than describing it as working.

Contents

Three manuals are planned. One is available now; the other two are in preparation and will be added as the facilities they cover are checked in continuous integration.

Installation Guide · Order number AA–OVMX3–IN

Installation Guide

Build the bootable image, boot it under QEMU, install the product kit onto a system disk, and log in. Every command is checked against the continuous-integration gate that boots OpenVMX and runs it.

Available

System Manager's Guide · Order number AA–OVMX3–SG

System Manager's Guide

Day-to-day operation of an installed system: accounts and the user authorization file, logical names, devices and volumes, and the startup sequence.

In preparation

Cluster Systems · Order number AA–OVMX3–CL

Cluster Systems

Joining a VMS-family cluster over the interconnect and the state OpenVMX reports through SHOW CLUSTER. V0.6 ships cluster participation — a distributed lock manager over the interconnect and membership in the executive; quorum/votes and serving an ODS-2 volume are not yet enforced. This manual is in preparation.

In preparation
