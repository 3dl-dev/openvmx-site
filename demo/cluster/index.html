A real VMScluster, running live in your browser.

This page hosts real, executive-backed VMS-compatible systems — not a simulation or a recording. Every node is a genuine, cold-booted VM running inside your browser tab.

Node A (OVMX/x86_64) is live: it boots the real OVMX kernel executive under QEMU-in-WebAssembly, and its virtual NIC emits real cluster-protocol frames (SCA, ethertype 0x6007) onto an in-page virtual Ethernet switch — pure JavaScript in your tab, no server, nothing shared between visitors.

Node B (OVMX/VAX) and Node C (a genuine VMS-family 5.5 system, the original DEC/VSI article) are staged, not faked: their panels exist but stay dormant until each node's real cluster join is independently proven. This page will never show a cluster member count it did not read live off a real executive's own membership state.

What's emulation, what's real: the CPUs are software emulation (QEMU-in-WASM / a JS VAX emulator). What runs on them is the genuine, unmodified article — OpenVMX's real executive, and real VMS on Node C.

The in-page cluster switch

The parent page is a virtual Ethernet switch (a dumb L2 broadcast hub): each node below is an iframe/port; a raw Ethernet frame in on one port floods to every other, verbatim — the exact bytes the real executive's NIC emits. Nodes B and C attach through the same frozen wire contract as soon as their own join is proven.
